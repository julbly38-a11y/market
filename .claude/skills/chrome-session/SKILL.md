# chrome-session

Відкриває Claude-сесію в Chrome. **Завжди окреме нове вікно, ніколи вкладка.**

Працює лише в Claude Code, запущеному з Chrome-інтеграцією (`claude --chrome`) на комп'ютері користувача. У хмарному контейнері Chrome немає, тоді скажи про це й зупинись.

## Вхідні дані

Запитай у користувача, якщо не вказано:
- **репозиторій** (за замовчуванням `julbly38-a11y/market`);
- **гілка** (необов'язково);
- **скільки сесій** відкрити (за замовчуванням одна).

## Кроки

1. Перевір, що інструменти Chrome-інтеграції доступні. Якщо ні, скажи: «Запустіть Claude Code з `claude --chrome`» і зупинись.
2. Для кожної сесії відкрий **нове вікно** Chrome з адресою `https://claude.ai/code`. Не використовуй «нова вкладка» і не відкривай посилання інструментом вкладок: він відкриває вкладку.
   - На macOS відкривай вікно командою в терміналі (Bash), по одній на сесію:
     `open -na "Google Chrome" --args --new-window "https://claude.ai/code"`
   - На Windows: `start chrome --new-window "https://claude.ai/code"`.
   - На Linux: `google-chrome --new-window "https://claude.ai/code"`.
   - Не покладайся на `window.open` чи створення вкладки в інтеграції: Chrome часто відкриває їх вкладкою у поточному вікні.
3. Далі для керування вмістом вікна використовуй Chrome-інтеграцію: у кожному вікні вибери репозиторій (і гілку, якщо вказана) та почни нову сесію. Одна сесія на одне вікно.
4. Перевір результат: перелічи відкриті вікна й переконайся, що кількість нових вікон дорівнює кількості сесій і жодне не відкрилось як вкладка в існуючому вікні. Якщо вийшла вкладка, закрий її лише якщо її створив ти, і повтори крок 2 командою.
5. Відповідай коротко, українською: скільки вікон відкрито і для якого репозиторію.

## Чого не робити

- Не відкривай сесії у вкладках наявного вікна.
- Не закривай і не змінюй чужі вкладки та вікна.
- Не вводь паролі й токени, якщо Chrome просить вхід, попроси користувача зробити це самому.
